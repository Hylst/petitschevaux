# À propos de Petits Chevaux

**Petits Chevaux** est le grand classique du jeu de société à dés et pions, développé par
**Geoffroy Streit** (alias **Hylst**).

## Le jeu

Quatre joueurs, quatre couleurs, un plateau en croix. Sortez vos pions sur un 6, faites-les
avancer autour du plateau, capturez les pions adverses en atterrissant sur leur case, et
ramenez vos 4 pions au centre avant les autres. Un 6, une capture ou l'arrivée d'un pion au
centre offre un tour supplémentaire — mais attention, trois 6 d'affilée annulent le tour.

« Petits chevaux » est le nom traditionnel français de ce jeu, dérivé de l'indien Pachisi
et connu ailleurs sous le nom de Ludo.

## Stack technique

- React 19, TypeScript 5.9 (strict), Tailwind CSS 4
- Vite 7, vite-plugin-singlefile
- Logique de jeu pure (reducer), rendu React/CSS
- Web Audio API pour les effets sonores
